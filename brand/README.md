# Kamal Jewellers — logo files

The mark is the same badge as before (black disc, gold lotus, brush-script KJ, gold-dust ring),
redrawn as clean vectors so it prints, foils and embosses identically at any size.

| Use | File |
|---|---|
| Everything digital, full colour | `kamal-logo.svg` / `kamal-logo-1024.png` |
| On photos or dark backgrounds, no black disc | `kamal-logo-transparent.svg` |
| **Hot-foil / gold stamping** (one flat colour) | `kamal-logo-gold.svg` — Pantone-match to `#C9A24B` |
| **Emboss, black ink, letterhead, light backgrounds** | `kamal-logo-black.svg` — `#171512` |
| Reversed on dark/brown | `kamal-logo-ivory.svg` — `#F3EEE4` |
| Below ~64 px (favicon, tiny icons) | `kamal-logo-small.svg`, `favicon-32.png`, `favicon-64.png`, `apple-touch-icon.png` |

Colours: gold gradient `#9A7127 → #D4A949 → #F2D88A → #FBEBB5`, disc `#050403`, flat gold `#C9A24B`.
Print: keep the badge at least ~18 mm across; use the small version below that.
Edit or regenerate everything with `python3 build-logo.py <outdir>`.

**In use on the site (Oct 2026):** `logo.png` (full mark, 256 px) and `logo-small.png` (simplified, nav/footer/Studio),
plus `favicon-64.png` and `apple-touch-icon.png` from this folder. `original-logo.png` is the previous artwork, kept for reference.
